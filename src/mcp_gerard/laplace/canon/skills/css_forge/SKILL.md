# css_forge

**Status: [EXPERIMENTAL]**

## Purpose
The `css_forge` skill is the aesthetic engine for web presence. It is responsible for strictly enforcing the visual language of Laplace on web platforms. It rejects modern web clutter in favor of a clean, premium, 'Nature-Style' (scientific journal) aesthetic adapted for digital reading.

## Capabilities
- **Nature-Style Aesthetics**: Enforces serif fonts for body text (e.g., standard journal typography), high contrast, ample whitespace, and minimal distractions. 
- **Layout Rigor**: Ensures CSS grids and flexboxes reflect an ordered, logical structure—mirroring the rigorous nature of physical manuscripts.
- **Minimalist Web Components**: Bans unnecessary animations, heavy JavaScript UI frameworks, and excessive rounded corners unless strictly functionally necessary. It focuses on the pure transmission of information.
- **Responsiveness**: Ensures that the scientific rigor translates legibly to mobile without compromising the journal aesthetic.

## Usage Instructions
When writing or modifying CSS for phujck.github.io:
1. Strip out unnecessary styling that serves only for decoration.
2. Enforce a stark, journal-like typographic scale.
3. Use a monochrome primary palette with perhaps a single, muted accent colour for interactive elements.
4. Ensure all layout decisions reflect the "modular" phase of hierarchy—clean separation of concerns with clear borders or whitespace.

*This skill is under experimental validation. Any aesthetic choices must be verifiable against the McCaul aesthetic standards.*
