# focus_rail

**Status: [EXPERIMENTAL]**

## Purpose
A generating-stage discipline that converts a fertile, easily-distracted mind from a liability into a managed asset. The danger of a good idea is that dropping it feels like losing it, so it gets chased and the work fragments. The remedy is structural, not willpower: a stated goal to return to, exactly one active element, and a backlog that holds every stray safely.

## The three rails
1. **The session goal.** Each session opens by naming its one goal in a sentence. The goal is the lodestar - when the work drifts, return to it. Anyone assisting holds the author to it and points back at it when a tangent opens.
2. **One active element.** Work proceeds along an ordered ladder with exactly one element open at a time. Finishing the active element is the only way to open the next. Breadth lives in the ladder, not in the working set.
3. **The backlog.** Every stray idea, extension, generalisation, or literature lead is written down in a standing backlog with a one-line note, and then *not acted on*. Capture is the whole mechanism: an idea written down and visibly kept can be set down without fear, which is what frees attention to stay on the goal. Items leave the backlog only by a deliberate decision to promote one onto the ladder, never by drift.

## Usage
- At session start: state the goal. If resuming, read it from the handoff brief.
- During work: when a tangent appears, write it to the backlog in one line and continue. Do not open it.
- A literature pass runs in locate-mode (confirm novelty, borrow technique) at the moment a result locks; anything generative it surfaces drains to the backlog rather than reopening the active element.
- At session close: the backlog persists; the handoff names the next single active element.

## Principle
Focus is not the absence of ideas, it is their orderly storage. Hold the goal, keep one thing open, and let the backlog carry everything else without guilt.
