# reference_archaeologist

**Status: [EXPERIMENTAL]**

## Purpose
A generating-stage skill for drawing on prior, stale, or foreign material without loading its raw context into the working session. An isolated agent reads the source exhaustively and returns only the structural skeleton. Framing, narrative, and prose stay at the source. The point is to keep established content available while its inherited framing never enters the live context.

## When to use
- A prior or superseded artifact holds results worth reusing, and loading it wholesale would import unexamined framing.
- Several versions of a source exist and their formal content may have diverged.

## Protocol
1. **Spawn a clean agent.** Give it the source paths and a strict output contract. It reads, the main context does not.
2. **Distil to the skeleton only.** The agent returns the canonical objects and notation, the formal model or equations, each result as one sentence with an honest status (established / partial-under-a-stated-restriction / open-gap), and every named gap or restriction.
3. **Diff the versions.** Where several versions exist, the agent compares a representative subset and reports formal differences in notation or model before settling what to return.
4. **Report through the firewall.** The distilled skeleton returns to the main context. A result enters the working project only by fresh re-derivation in the project's own vocabulary, with provenance noted, never as imported text.

## Principle
What crosses is reconstructed mathematical content, not inherited meaning. The skeleton is a starting point for re-derivation, and any evocative name from the source is a candidate to be earned rather than adopted.

*Experimental and coarse by design. Refine whenever a retrieval reveals a sharper output contract.*
