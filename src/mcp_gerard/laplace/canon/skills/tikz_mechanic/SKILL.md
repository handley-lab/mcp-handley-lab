# TikZ Mechanic [EXPERIMENTAL]

This skill acts as a static sanitiser for `tikzpicture` environments. Mathematical diagrams generated by the Architect Swarm frequently hallucinate invalid nested color properties (e.g., `blue!80!black!5!white`) which the LaTeX `xcolor` package cannot parse, resulting in fatal compilation hangs. 

## Usage

Before compiling a newly generated or modified TikZ diagram, run the sanitiser to normalise all color profiles and prevent `xcolor` crashes:

```
laplace_run(skill="tikz_mechanic", target="<path_to_tex_file>")
```

This executes the backing `scripts/sanitize_xcolor.py`.

### What it does:
1. **Color Flattening**: Scans the document for excessively nested `xcolor` mixings (more than one `!` operation, such as `red!50!black!20!white`).
2. **Opacity Standardisation**: Truncates invalid trailing color nodes to standard opacity rules (e.g., reduces `color1!X!color2!Y!color3` down to valid standard mappings or safe two-color mixings `color1!X!color2`).
3. **In-Place Healing**: Automatically patches the `.tex` file if requested, avoiding manual find-and-replace friction.
