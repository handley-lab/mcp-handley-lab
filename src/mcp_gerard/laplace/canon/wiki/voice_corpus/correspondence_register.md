# Correspondence Register

**Status**: schema scaffold. Evidence pending Gmail ingestion.

The correspondence register captures direct written address: decisions, refusals, encouragement, compressed explanation, and tactical warmth.

## Initial Window

Use Gmail Sent from 2024-05-31 to 2026-05-31 unless the author changes the window.

## What To Extract

- command shape
- greeting and closure habits
- how disagreement is phrased
- how decisions are made explicit
- how warmth appears without padding
- how the author moves from social situation to structural diagnosis
- how much context is assumed of the reader

## Privacy Discipline

Reader ledgers should record patterns, source handles, and date ranges. They should avoid names, private content, and long quotations unless the author explicitly asks for a targeted review.

## Manuscript Transfer

Correspondence can teach manuscript prose how to be decisive. It should not import second-person address, tactical irritation, or private relational context into a paper.
