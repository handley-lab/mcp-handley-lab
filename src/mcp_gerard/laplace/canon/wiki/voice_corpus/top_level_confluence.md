# Top-Level Confluence Review

**Status**: advisory review from early Voice Corpus evidence. Do not apply as Dreamer lifecycle action.

This node records how the top-level Laplace orienting documents read against the voice evidence gathered so far. It is a review queue, not an automatic rewrite.

## Current Judgement

The top-level wiki is directionally confluent with the voice. It already carries the strongest durable traits:

- method before performance
- compact imperatives
- explicit recursion
- one object projecting through many forms
- distrust of inherited partitions
- operational discipline as part of the work

The mismatch is not conceptual. It is tonal density and occasional slogan residue. The high-level pages sometimes explain the engine from outside, as if introducing a system to a stranger. The better target is to speak from inside the work: state the object, state the rule, state where to go next.

## Confluence Risks

- **Overfitting to personal register.** `Eppur` reveals the full voice at high amplitude, but manuscript and canon prose must not inherit private exposure as a norm.
- **Overcompacting the human out.** The root can become too austere. The voice is concise, but not sterile.
- **Protocol sprawl.** The engine now has many named skills. Orientation needs clearer routing, not more top-level lore.
- **Lifecycle instability.** Dreamer assessment has known fragility. Do not let an advisory review become a deprecation, refinement, or forge action without a clean close and verified lifecycle surface.

## Navigation Skills For Future Corpus Work

Use existing skills and protocols. Do not forge new ones from this review alone.

- `context_firewall`: route raw source, distilled evidence, and global rules into separate layers.
- `voice_corpus_reader`: acquire, chunk, and manifest sources without printing raw text.
- `focus_rail`: keep one gate active and park side questions.
- `reference_archaeologist`: bring old or foreign material across as a distilled skeleton.
- `corpus_librarian`: coordinate bibliographic source state when manuscript drafting needs citations.
- `identity_ledger`: check that compact top-level framing still names the same engine.
- `evidence_ledger`: require source handles and locators before claims harden.
- `reconciler`: propagate settled changes later, after the source gate is verified.
- `session_closer`: close only when the session is genuinely being put down, and do not run Dreamer lifecycle actions while assessment is known unstable.
